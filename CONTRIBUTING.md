# Contributing to GreenRoute Campus

Thanks for helping improve the project.

## Before opening an issue

- Check existing issues and pull requests.
- Reproduce bugs with the latest `main` branch when possible.
- Never post API keys, passwords, session cookies, `.env` files, or private user data.

## Development

1. Create a virtual environment.
2. Install dependencies with `python -m pip install -r requirements.txt`.
3. Copy `.env.example` to `.env` if configuration is needed.
4. Run the app with `./run.sh` on Linux/macOS or `run.bat` on Windows.
5. Run `pytest -q` before submitting a pull request.

## Pull requests

Keep changes focused and explain what was changed and how it was tested. Update the README or other documentation when behavior or setup changes.
