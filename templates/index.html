THE PROBLEM → THE SOLUTION

Students know the destination. They usually don't know the trade-off.

GreenRoute makes hidden commute outcomes visible and gives the campus a feedback loop: plan → act → measure → learn.

01Invisible impactCost, CO₂ and activity are rarely shown together.
02Fragmented choicesBus, metro, walking, cycling and carpooling are not compared in one place.
03No feedback loopRepeated choices become meaningful only when the ledger measures them.
04No campus evidenceAdministrators need patterns that can be inspected and exported.

TECHNICAL DEPTH

Built like a product, not a slide deck.

Each external dependency has a fallback path so the core demo remains usable.

01Flask + SQLiteSessions, roles, foreign keys, indexes and seeded demo data.
02OSRM + fallbackRoad geometry when available; Haversine fallback keeps the planner alive.
03Open-Meteo + fallbackWeather/AQI context with safe defaults.
04AI + MLCloud natural-language reasoning plus local intent/recommender fallbacks.
05PWA shellInstallable responsive interface with dark mode.
06SecurityHashed passwords, CSRF, validation and rate limiting.
